# 送迎表　導入手順

## 全体の形

```
スプレッドシート1つで完結します

  ①施設・車両設定 ②利用者一覧   ← 先方が入力する
        │ 1時間ごとに自動で反映
        ▼
  ③座標 ④実測                    ← 自動で作られる（一度測った区間は保存）
        ▼
  月曜の送迎表 … 土曜の送迎表      ← 自動で作られる。見るだけ・印刷するだけ
        │ 同時に書き出す
        ▼
  送迎データ_月曜 … _土曜（Gem用）  ← Gem「送迎配車アシスタント」が読む
```

- 正式な送迎表はスプレッドシートにあります（印刷用）
- Gem には、計算済みの送迎表と地点どうしの移動時間を渡します。Gem は表を見せ、頼まれたら組み替えて、短いコードで時刻を計算し直します
- Gem 用のデータに住所は入れていません（地点は「P3：○○小学校」のような番号と名前）
- APIキーは不要です。先方は自分の Gemini で Gem を開くだけです

---

## 船井がすること（事業所ごとに1回・15分）

1. `設定シート.xlsx` を Googleドライブに上げ、**ファイル → Googleスプレッドシートとして保存**
2. **拡張機能 → Apps Script** で `コード.gs` の中身を `送迎メニュー.gs` に置き換えて保存。シートを再読み込み（F5）
3. ①②を入力する（または先方に入力してもらう）
   - ①：施設名、施設住所、10行目から車両名（A列）・定員数（C列）
   - ②：氏名・お迎え先・住所・曜日セル（`○(迎え14:10、送り17:55)` の書き方でよい）
4. **🚐 送迎 →【初回】自動更新をONにする**
   - 承認画面が出たら **詳細 → 移動 → 許可**
   - 住所を調べ、移動時間を測り、曜日ごとの送迎表を作る。最長5分ほど
   - 利用者が多いと移動時間の測定が1回で終わらないが、1時間ごとに自動で続きを測る
5. `⚠要確認` シートが出たら、書いてある箇所を直す（住所の空欄など）
6. シートを先方に共有する（編集者）
7. **Gem を作る**（先方の Gemini で。船井が横で一緒に操作する）
   - Gemini → Gem マネージャー → 新しい Gem。名前：`送迎配車アシスタント`
   - 「カスタム指示」に `Gem指示文.md` の中身を全部貼る
   - 「知識」に、ドライブから **送迎データ_○曜（Gem用・自動更新）** を曜日の数だけ追加（スプレッドシートと同じフォルダにある）
   - 「デフォルトツール」でコードの実行ができる設定があれば有効にする。保存
   - 新しい会話で「水曜のお迎えを見せて」→ 送迎表シートと同じ表が出ればOK

## 先方の日々の使い方

| やりたいこと | すること |
|---|---|
| その日の送迎表を見る | **「○曜の送迎表」シートを開く**。お迎え・お送りの便ごとに、車・順番・時刻が出ている |
| 話しかけて相談・組み替え | **Gem「送迎配車アシスタント」**に「今日の送迎」「2号車は車検。ヤマダさん休み。サトウさんは1号車に」など。Gem が組み替えて時刻を出す（会話の中だけ。正式な表にするなら下の黄色い欄に書く） |
| 使えない車がある | その曜日のシートの上、黄色い **「使わない車」** に車両名を書く（例：`シエンタ２号`） |
| お休みの方がいる | 黄色い **「お休みの方」** に名前を書く（名前の一部でよい） |
| クラブ活動の日・送りありの日 | 黄色い **「別案で送迎する方」** に名前を書く（②の「/」の後ろに書いた時刻で組む） |
| この子はこの車にしたい | 黄色い **「車の固定」** に `サトウ→1号車` と書く（お迎えだけなら `サトウ→1号車(お迎え)`）。ほかの方はその残りで組み直す |
| 利用者・住所・時刻が変わった | ②を直すだけ。1時間以内に反映。急ぐときは **🚐 送迎 → 今すぐ送迎表を作り直す** |
| 車が増えた・定員が変わった | ①を直すだけ |

- 黄色い欄に書くと、**数十秒でその曜日だけ組み直されます**。Gem 用のデータも同時に書き直されます
- 黄色い欄は、**その日が終わったら消してください**（残すと翌週も外れたままになります）
- 外している車は、送迎表の上に赤字で「○○を外して組んでいます」と出ます

## 困ったとき

| 症状 | 対処 |
|---|---|
| 🚐 送迎 のメニューが出ない | シートを再読み込み（F5） |
| 直したのに送迎表が変わらない | 🚐 送迎 → 今すぐ送迎表を作り直す |
| 特定の人が出てこない | `⚠要確認` シートを見る（住所の空欄・見つからない住所） |
| 赤字の「未割当」が出る | 車が足りません。同じ学校・同じ時刻の子は同じ車に乗せる決まりなので、席の組み合わせで乗り切れないこともあります |
| 赤字の「○分遅れ」が出る | 指定時刻に間に合っていません。出発を早めるか、車を増やす |
| 「まだ移動時間を測れていない」と出る | 自動更新で順に測っています。しばらくすると消えます |
| Gem の表がシートと違う | Gem の知識のドキュメントが古い。スプレッドシートで「今すぐ送迎表を作り直す」を押し、Gem で新しい会話を始める。それでも古ければ知識のドキュメントを入れ直す |
| Gem が「コードが実行できない」と言う | 組み替えの時刻計算だけができない状態。基本の送迎表は見られる。組み替えは送迎表シートの黄色い欄で行う |

**時刻は目安です。** Googleマップで測った移動時間を使っていますが、当日の渋滞は読めません。最終判断は人がしてください。
