# 送迎配車アシスタント　導入手順

## 全体の形

```
先方のスプレッドシート（①施設・車両　②利用者）
   │ 保存すると、1時間以内に自動で反映
   ▼
送迎データ（Gem用・自動更新）   ← 座標・移動時間はここに保存済み。毎回は測らない
   │
   ▼
Gem「送迎配車アシスタント」      ← 船井が作って先方に共有。計算は固定
```

**先方がすること**
- 名簿が変わったら、スプレッドシートを直して保存する
- Gemに「今日の配車」と言う（使えない車があれば「2号車は使えない」と添える）

---

## 船井がすること（事業所ごとに1回・20分）

### 1. シートを渡す
1. 配布用の `/copy` リンクを先方に送る。先方が「コピーを作成」し、**そのシートを船井に編集者として共有**してもらう
2. 先方に ① と ② を記入してもらう（②は曜日セルに `○(迎え14:10、送り17:55)` の書き方でよい）

### 2. 仕組みを動かす（先方のシートで、船井のアカウントで操作）
1. **🚐 送迎 →【初回】自動反映をONにする**
   - 承認画面が出たら **詳細 → 移動 → 許可**
   - 座標と移動時間の測定が始まる。利用者50名ほどなら数回の自動反映（数時間）で測り終わる
2. `⚠要確認` シートが出たら、書いてある箇所を先方に直してもらう（住所の空欄、Googleが見つけられない住所など）

### 3. Gemを作って共有する
1. **🚐 送迎 →【初回】Gemの準備**。出てきた画面のとおりに：
   - Gemini → Gem マネージャー → 新しい Gem（名前：`送迎配車アシスタント`）
   - 「指示」に枠の中身を貼る
   - 「知識」に `配車ロジック.py` と `送迎データ（Gem用・自動更新）` を追加
   - **「コード実行」を有効にする**
   - 保存
2. Gemを先方のアカウントに共有する

### 4. 確認
Gemで「水曜のお迎えを組んで」と打ち、1行目に `［配車ロジック 2026-09-24］` が出て、車ごとの表が出ればOK。

---

## 先方の日々の使い方

| やりたいこと | すること |
|---|---|
| その日の配車 | Gemに「今日の配車」 |
| 使えない車がある | 「2号車は使えない」と添える |
| 欠席がいる | 「○○さん欠席」と添える |
| クラブ活動の日など | 「○○さんクラブ活動あり」と添える（②に書いてある別の時刻で組む） |
| 利用者・住所・時刻が変わった | ②を直して保存。1時間以内に反映。急ぐときは **🚐 送迎 → 今すぐGemに反映する** |
| 車が増えた・定員が変わった | ①を直して保存 |

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「コードが実行できない」と言われる | Gemの設定で「コード実行」を有効に（船井） |
| 表ではなく文章で答える | モデルを **Pro** にする |
| 直したのに反映されない | 🚐 送迎 → 今すぐGemに反映する。それでもだめなら Gem の知識のドキュメントを入れ直す |
| 特定の人が出てこない | `⚠要確認` シートを見る（住所の空欄・見つからない住所） |
| ⚠未割当・⚠遅れ が出る | 車が足りていません。出発を早めるか、車の組み合わせを変える |

**時刻は目安です。** Googleマップで測った移動時間を使っていますが、当日の渋滞は読めません。最終判断は人がしてください。
