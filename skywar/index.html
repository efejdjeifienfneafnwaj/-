蒼穹艦隊戦

SKY FLEET ─ 飛行戦艦 vs 飛行空母

西暦2189年。雲海の上空で、自軍旗艦「アマテラス」と敵飛行空母「ベヒモス」が激突する。
あなたはジェットブースター装備の強襲兵として格納庫から出撃し、敵空母を撃沈せよ。

操作説明

マウス視点移動
W / A / S / D前進 / 左 / 後退 / 右
スペース / C（Ctrl）上昇 / 下降
Shift（押しっぱなし）ジェットブースト（高速移動）

作戦目標

  1. 敵空母の対空砲台（6基）を全て破壊し、機関部のシールドを解除せよ。
  2. 空母後部の機関コア（2基）を破壊して撃沈せよ。
  3. 敵空母の主砲（黄色いプラズマ弾）は旗艦を狙う。撃ち落として旗艦を守れ。
  4. 自軍の格納庫に戻ると機体の修理とミサイル補給ができる。

敗北条件：あなたの機体、または旗艦「アマテラス」の耐久が0になる。
