# 個別支援計画 作成支援アプリ

児童発達支援・放課後等デイサービス向けの、個別支援計画づくりを支援するアプリです。
ビルドや会員登録は不要で、`index.html` を開くだけで動きます。

## できること

- **児童の登録・一覧** — 児童ごとに基本情報・保護者情報などをまとめて管理
- **発達アセスメント** — 5領域(健康・生活／運動・感覚／認知・行動／言語・コミュニケーション／人間関係・社会性)×14項目=70項目のチェック。半年ごとのモニタリングのタイミングで記録すると、前回との変化(できるようになったこと・芽生えていること)が自動でまとまり、保護者にお渡しするA4シートを印刷できます
- **個別支援計画** — 5領域ごとに目標・支援内容を書く様式。アセスメントの結果から下書きを自動で差し込めます。印刷、および**厚生労働省の参考様式(別紙1-1／1-2)に沿ったExcel(.xlsx)での書き出し**に対応
- **専門的支援実施計画** — PT/OT/ST/心理担当職員などが行う支援の計画と、実施のたびの記録
- **記録・文字起こし** — 面談や観察の記録を児童ごとに蓄積。ブラウザの音声入力にも対応(利用前に確認ダイアログを表示)

## データの保存について

すべてのデータは、この端末の**ブラウザの中(localStorage)だけ**に保存されます。
インターネットへ送信されることはありません。そのぶん、ブラウザの閲覧履歴を消すと
データも消えるため、「設定・データ」画面から定期的にバックアップ(JSON)を保存してください。

## 使い方

`index.html` をブラウザで開くだけで起動します。Webサーバーは不要です。

## Excel様式について

`js/xlsx-template.js` には、厚生労働省が公表している個別支援計画の参考様式
(別紙1-1・別紙1-2)の xlsx をそのまま部品化して埋め込んでいます。
様式そのものを更新する場合は、新しい様式ファイルを用意して以下を実行してください。

```bash
python3 tools/build-template.py <新しい参考様式.xlsx>
```

## 構成

```
index.html          画面の入れ物
css/style.css        画面表示用スタイル
css/print.css        印刷(A4)用スタイル
js/data.js           5領域・発達チェック項目などのマスタ
js/store.js          保存・読み込み・バックアップ(localStorage)
js/ui.js             共通のDOM操作・日付処理
js/assess.js         発達の目安月齢の算出・前回比較・レーダーチャート
js/print.js          印刷帳票の組み立て
js/xlsx.js           厚労省様式へのExcel書き出し
js/xlsx-template.js  埋め込んだExcel様式(自動生成)
js/view-*.js         各画面(児童/アセスメント/計画/専門的支援/記録)
js/app.js            画面遷移・全体の枠組み
tools/build-template.py  Excel様式の埋め込みを作り直すスクリプト
```
