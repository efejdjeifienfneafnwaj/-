# 加湿 CO₂ の高速流量切替供給系 — 設計計算書

**要求仕様**

| 項目 | 値 |
|---|---|
| 出力段 CO₂ ガス圧 | 20 kPa（**ゲージ**、大気圧 +20 kPa） |
| 出力段温度 | 20 °C |
| 出力段相対湿度 | 70 % |
| 流量 | 30 NLPM ⇄ 15 NLPM を **30 ms ごと**に交互・連続切替 |
| ガス源 | 相対湿度 約 90 % の CO₂ |

## 0. 結論（先に）

**達成可能である。** ただし成立には 3 つの設計判断が要る。

1. **流量切替素子はサーマル質量流量計（MFC）では不可能。** 市販最速でも整定 300 ms で、
   切替周期 60 ms の 5 倍。センサ管の熱時定数による物理的限界であり、調整では解決しない。
   → **固定臨界ノズル 2 本 + 高速電磁弁**（SMC SX10: 0.45 ms、Festo MHJ10: <1 ms）を使う。
2. **「圧力を静かに保つこと」と「30 ms の流量変調を保つこと」は同じ容積では両立しない。**
   ±0.5 % の圧力安定に必要な 2.65 L のプレナムは滞在時間 7.9 s（切替周期の 132 倍）で、
   流量変調を完全に消してしまう。
   → **排気側オリフィスを入口弁と同期して切り替える**ことで初めて両立する。
3. **最も厳しい制約は圧力ではなく温度。** dRH/dT = **−4.32 %RH/K**（18–22 °C の割線では −4.34）。
   RH を ±1 % に保つには出力段温度を **±0.23 K** に制御しなければならない。
   圧力は ±1.76 kPa でよく、設計上は容易である。

## 1. 系統構成

```
CO2ボンベ ─ 一次減圧弁(300 kPa abs) ─ 恒温飽和器(30.66 °C, RH 90%)
                                            │  ← トレース加熱 34 °C（単調な温度勾配）
                                      一次プレナム 0.5 L
                                            │
                        ┌───────────────────┴───────────────────┐
                 臨界ノズル A                              臨界ノズル B
                 のど径 0.869 mm                          のど径 0.869 mm
                 （常時開・15 NLPM）                      （高速弁 V1 で開閉・+15 NLPM）
                        └───────────────────┬───────────────────┘
                                   出力プレナム 100 mL（20.0 ± 0.2 °C 恒温、弁から 25 mm 以内）
                                   ＝ 出力段：121.325 kPa abs / 20 °C / RH 70 %
                                            │
                        ┌───────────────────┴───────────────────┐
                 排気オリフィス C                          排気オリフィス D
                 φ1.937 mm（常時開）                      φ1.937 mm（高速弁 V2）
                        └───────────────────┬───────────────────┘
                                    V2 は V1 と同一信号で駆動（同期切替）
```

**同期切替が要点である。** 入口が 15→30 NLPM に上がるのと同時に排気コンダクタンスも 2 倍になるため、
定常状態では**どちらの流量でも 20 kPa ゲージ**になる。圧力変動は弁の同期ずれの間だけ生じる。

## 2. 状態点

一次側 300 kPa abs、飽和器 30.655 °C（RH 90 %）、トレース加熱 33 °C とした場合：

| 状態点 | T [°C] | p [kPa abs] | RH [%] | 露点 [°C] | 結露余裕 [K] | f |
|---|---|---|---|---|---|---|
| S1 飽和器出口 | 30.655 | 300.000 | 90.00 | 28.82 | **1.83** | 1.0386 |
| S2 ノズル上流 | 33.000 | 300.000 | 78.89 | 28.84 | 4.16 | 1.0376 |
| S3 ノズル下流 | 31.161 | 121.325 | 36.16 | 14.40 | 16.76 | 1.0159 |
| S4 出力段 | 20.000 | 121.325 | **70.00** | 14.37 | **5.63** | 1.0180 |

保存量：水蒸気モル分率 **x_v = 13 739 ppm = 1.374 mol%**
混合比 w = 5.702 g/kg（乾き CO₂ 基準）、絶対湿度 12.32 g/m³

### 2.1 なぜ膨張しても結露しないか（定量）

JT 膨張（300 → 121.3 kPa、Δp = 1.787 bar、μ_JT ≈ 1.05 K/bar）による冷却は **−1.82 K** にすぎないのに対し、
分圧低下による露点降下は **−14.4 K** である。**露点降下が JT 冷却を約 8:1 で上回る**ため、
加圧側で飽和したガスを膨張させる操作は本質的に安全側である（S3 の余裕は 5.2 K → 17.8 K に増える）。

危険なのは逆順序、すなわち**減圧後に加湿してから下流で冷える**経路である。
したがって**減圧弁は必ず最終加湿・最終温調より上流に置く**。

ドライアイス生成の懸念は不要である。CO₂ 三重点は 216.592 K / 517.95 kPa、1 atm 昇華点は 194.7 K。
JT だけでそこへ到達するには約 89 bar の差圧が要り、本系の 2.8 bar とは 32 倍の開きがある。

### 2.2 結露余裕の予算

出力段で使える余裕は **5.63 K しかない**（20 °C − 露点 14.37 °C）。
分析配管で慣用される「露点 +20 K」は**ここでは使えない**——20 °C の仕様が壊れるからである。
適用すべき下限は **US EPA Method 320 の「露点より最低 5 °C 高く」** である。

余裕は温度の*均一性*で買う：

- RTD を 3 点以上分散配置し、単一点制御にしない
- バルブ本体・継手・T 分岐・センサボスの冷点を無くす（金属部は熱橋になる）
- 温度プロファイルを**単調**にする（上流ほど高温、局所極小を作らない）
- 濡れ面は PFA/PTFE（ステンレスは RH 依存の水分吸着で高速応答を鈍らせる）

## 3. 流量切替

### 3.1 基準条件の明示（誤差源として最大）

「NLPM」は基準条件を書かないと意味を持たない。

| 基準 | T_ref | V_m [L/mol] | 30 NLPM の質量流量 |
|---|---|---|---|
| **DIN 1343:1990**（= SEMI E12-0303） | 0 °C | 22.4140 | **0.9738 g/s** |
| ISO 13443:1996（= ISO 2533 海面） | 15 °C | 23.6448 | 0.9231 g/s |
| ベンダ慣行（Sensirion 等） | 20 °C | 24.0551 | 0.9074 g/s |

0 °C 基準と 20 °C 基準の差は **7.32 %** で、良質な臨界ノズルの不確かさ 0.2 % の **35 倍**である。
**論文では質量流量 g/s を主表記とし、NLPM は基準条件を併記して従で書くこと。**
（注：ISO 2533 は 15 °C であって 0 °C ではない。SEMI E12 は 0 °C であって 20 °C ではない。
両方とも文献でしばしば取り違えられている。）

### 3.2 臨界ノズル（ISO 9300:2022）

一次 300 kPa abs、33 °C、γ_mix = 1.300（実在気体）：

- 臨界流関数 C* = 0.6720（実在気体補正 C_R = C*/√Z₀ 込み）
- **のど径 0.869 mm × 2 本**（A：常時 15 NLPM、B：切替 +15 NLPM）
- Cd = 0.9833（ISO 9300:2022 トロイダル式 Cd = 0.9959 − 2.720·Re^−0.5）、Re_t = 4.64×10⁴
- 臨界圧力比 0.5457 に対し実際の背圧比 **0.4044** → 余裕 0.141 で確実にチョーク

チョークしている限り**流量は下流圧に一切依存しない**。これが出力段の圧力リプルから
流量設定を切り離す唯一の機構であり、臨界ノズルを選ぶ最大の理由である。

**CO₂ 固有の注意（必ず論文に書くこと）:** CO₂ は振動緩和時間がのど滞在時間と同程度になるため、
実効 γ が平衡値 1.289 とも凍結値 1.4 とも異なり、**Cd が最大 2 % ずれる**
（Johnson & Wright, *Flow Meas. Instrum.* **11**, 315, 2000）。ずれはのど径に依存する。
空気で 0.2 % のノズルが CO₂ では 2 % になりうる。**CO₂ で、実機ののど径で校正すること。**
設計 Re = 4.7×10⁴ は ISO 9300 の有効範囲下限近傍（境界層遷移域）でもあり、二重に校正が必要である。

### 3.3 アクチュエータ

| 方式 | 応答 | 判定 |
|---|---|---|
| サーマル MFC（Bronkhorst IQ+FLOW 最速） | 300 ms | **不可**（周期の 5 倍。熱時定数による物理限界） |
| ピエゾ比例弁（Festo VEMP） | 15 ms | 不可（周期の 1/4、角波にならない） |
| **高速電磁弁 SMC SX10** | **ON 0.45 / OFF 0.40 ms、1200 Hz** | **採用** |
| **Festo MHJ9 / MHJ10** | **<1 ms、1000 Hz** | 採用可 |

スパイク＆ホールド駆動が前提。弁は流量制限要素にならないよう余裕をもって選ぶ（律速はノズル）。

## 4. 圧力安定性 — 本設計の核心

### 4.1 固定排気では成立しない

排気を 15 NLPM で合わせた固定オリフィス（φ1.937 mm）に 30 NLPM を流すと、
出力段は **86.3 kPa ゲージ**まで上がる（目標 20 kPa）。亜音速オリフィスは
q ∝ √Δp なので流量 2 倍には Δp 4 倍が要るためである。**固定排気では仕様を満たせない。**

### 4.2 受動バッファだけでも成立しない

100 mL プレナムに流量変調を与えたときの圧力リプルは

Δp_pp = D(1−D)·Δṅ·T_p·n·R·T / V = **5.29 kPa（設定圧の 26.5 %）**

±0.5 % に収めるには **V = 2.65 L** が必要で、その滞在時間は **7.93 s = 切替周期の 132 倍**。
これは完全なローパスフィルタであり、**30 ms の流量変調が下流で消える**。
「静かな圧力」と「速い流量変調」は同一容積では両立しない。

### 4.3 同期排気切替による解

入口弁 V1 と排気弁 V2 を同一信号で駆動すると、定常状態ではどちらの流量でも 20 kPa になる。
残留リプルは**弁の同期ずれ Δt の間だけ**発生し、

Δp = Δṅ·Δt·n·R·T / V

| V₂ | Δt = 0.2 ms | 0.5 ms | 1.0 ms | 2.0 ms |
|---|---|---|---|---|
| 20 mL | 1.77 % | 4.41 % | 8.82 % | 17.6 % |
| 50 mL | 0.71 % | 1.76 % | 3.53 % | 7.06 % |
| **100 mL** | **0.35 %** | **0.88 %** | 1.76 % | 3.53 % |
| 200 mL | 0.18 % | 0.44 % | 0.88 % | 1.76 % |

**100 mL + Δt = 0.5 ms → 176 Pa（0.88 %）**。受動のみに対し **30 倍**の改善。
このリプルが RH に与える誤差はわずか 0.10 %RH である。

同期精度を上げるには、V1 と V2 に同一型番・同一ロットの弁を使い、駆動回路を共通化し、
配線長を揃える。オシロで両者の開閉時刻を実測して電気的に遅延補正すれば 0.2 ms も現実的である。

### 4.4 制御器で潰すことはできない

| 機種 | 応答 | 周期比 |
|---|---|---|
| Equilibar ドームロード背圧弁 | ~10 ms（機械式、最速級） | 0.17 |
| Alicat PC シリーズ | 30 ms（閉ループ） | 0.5 |
| Tescom ER3000 | 552 ms | 9.2 |

16.7 Hz（周期 60 ms）に対し、最速の Equilibar でも 1 周期あたり数サンプルしか取れない。
**背圧弁は平均圧の保持のみに使い、リプルは受動容積＋同期排気で処理する。**
（なお Alicat のカタログにある「<1 ms」「<10 ms」はセンサ応答と表示応答であって制御応答ではない。）

### 4.5 音響

- 音速：**266.4 m/s**（平衡）／278.5 m/s（凍結振動、高周波極限）— 4.5 % の分散がある
- **集中定数モデルの限界長：26.7 mm**（弁の立上り 1 ms で判定、L < c·t_r/10）
  → 弁・ノズル・出力プレナムは 25 mm 以内に一体化すること（本設計の既定値）。
  0.3 m の配管を引くと集中定数近似が破れ、伝送線路として扱う必要が生じる
- ヘルムホルツ共鳴（100 mL、首部 φ10 × 30 mm）：**203 Hz** = 切替基本波 16.7 Hz の 12 倍。
  第 5 高調波（83 Hz）より十分上にあり安全。**首部を φ6 × 100 mm にすると 60 Hz 台に落ちて危険**なので、
  プレナム形状は必ずこの式で確認すること
- 半周期あたりの掃気体積 **13.36 mL** → 切替弁下流の死容積は **2.7 mL 以下**に抑える

## 5. 湿度の物理 — CO₂ をキャリアとする場合の注意

### 5.1 相対湿度の定義

RH ≡ x_v / x_v,sat(T, p, CO₂)、ただし x_v,sat = **f(T,p)·p_sat(T)/p**

f はキャリアガスに依存する**エンハンスメント係数**である。WMO の定義自体が f を含んでおり、
その f は**空気についてのみ**表化されている（Lovell-Smith et al., *Metrologia* **53**, R40, 2016）。

### 5.2 空気用の f を CO₂ に使ってはいけない

Greenspan (1976) の式は表題からして "**CO₂-free** moist air" 用である。

| 20 °C | f_air | f_CO₂ | 比 |
|---|---|---|---|
| 101.3 kPa | 1.0040 | 1.0151 | 1.011 |
| **121.3 kPa** | **1.0046** | **1.0180** | **1.013** |
| 250 kPa | 1.0084 | 1.0367 | 1.028 |
| 400 kPa | 1.0128 | 1.0589 | 1.046 |

違いの源は交差第 2 ビリアル係数である：
B₁₂(H₂O–CO₂) = **−235.5 cm³/mol** に対し B_aw(H₂O–空気) = −32.0 cm³/mol（20 °C）。
CO₂ の四重極と水の双極子の強い引力による。**約 7 倍**である。

**空気用の f を使うと、121.3 kPa で飽和水分量を 1.3 % 過小評価し、RH を 0.93 %RH 過大報告する。**
これは p_sat の不確かさ（0.025 %）の 50 倍以上であり、本系で最も見落とされやすい補正である。

### 5.3 採用した定式化

ln f = ln φ_sat − ln φ_w + v_wL(p − p_sat)/RT + ln a_w

- ln φ_sat = B_ww·p_sat/(RT)
- ln φ_w = [2(x_v·B_ww + x_g·B₁₂) − B_mix]·p/(RT)、B_mix = x_v²B_ww + 2x_v x_g B₁₂ + x_g²B_CO₂
- Poynting 項：液相が全圧で圧縮される効果
- **ln a_w：溶存 CO₂ による水の活量低下**（IAPWS G7-04、k_H = 145 MPa @20 °C）。
  f を 121 kPa で 0.07 %、400 kPa で 0.28 % *下げる*。空気では約 1/25 で無視されるが、
  CO₂ では符号の定まった実在の効果である

x_v について不動点反復（3 回で 10⁻⁹ に収束）。

### 5.4 定式化の検証

**同じ式に空気の B_aw を入れて CIPM-2007 の f を再現できるか**で検証した。
0–40 °C / 80–400 kPa の全点で **残差 394 ppm 以下（rms 180 ppm）**、
そのとき得られる B_aw(20 °C) = **−32.0 cm³/mol** は文献値（−30〜−34、Harvey & Huang の第一原理計算）
の範囲内にある。これが CO₂ への適用を正当化する根拠である。
残差は第 3 ビリアル項に由来し、これが本手法の精度の下限を与える。

さらに、独立に実装された 2 つの計算が f_CO₂(121.3 kPa, 20 °C) = 1.0180 で **3.5×10⁻⁵ 以内**に一致した。

### 5.5 混合比の ε

ε_CO₂ = M_H₂O/M_CO₂ = 18.015/44.009 = **0.40935**

空気の 0.622 をそのまま使うと**混合比が +51.9 % の誤り**になる（丸め誤差ではなく 1.5 倍の誤り）。

## 6. 熱・水収支

| 項目 | 値 |
|---|---|
| 蒸発させる水（30 NLPM、乾ガスから RH 70 %） | **19.88 g/h** |
| 潜熱負荷 | **13.54 W** |
| 顕熱（S3 32.2 °C → S4 20.0 °C） | **−10.12 W**（冷却） |
| 顕熱係数（30 NLPM） | 0.833 W/K |
| 配管放熱（φ8、25 mm、無保温） | 約 0.1 W |
| **ヒータ／ペルチェ推奨容量** | **約 71 W**（計算値の 3 倍）→ 実装は 100 W 級 |

過大なヒータは禁物である。オーバーシュートで 20 °C を超えると RH が下がって仕様を外れる。

**飽和器は必ず恒温制御すること。** 蒸発潜熱 13.5 W による自己冷却で放置するとドリフトする。
NIST の一次湿度発生器（HHG）は槽を 1 mK で制御している。本系では **±0.1 K** を目標とする。

**加湿方式**：15–30 NLPM・定常なら
- **Bronkhorst CEM**（液体質量を計量するため重量トレーサブル、1–100 g/h。19.9 g/h は中央）
- **Perma Pure Nafion**（CO₂ は Nafion を透過しない。CO₂ バイアス ≈ −0.05 ppm と実測報告あり。
  ただし 30 NLPM は MH シリーズの 20 L/min を超えるので FC125 クラスが必要）
- バブラーは飛沫同伴で見かけ RH が 100 % を超えうる。5.6 K の余裕しかない本系では危険。
  使うならデミスタ＋下流再加熱を必須とする

加湿器そのものを 30 ms で変調することは**どの方式でも不可能**である（膜の含水量緩和、液体 MFC 整定、
槽の熱容量がいずれも秒オーダー）。本設計では**湿度は定常に保ち、流量だけを切り替える**——
これが構成上の重要な選択である。

## 7. 材料

湿潤 CO₂ の凝縮水は **pH 3.6–3.9**（炭酸、1–4 bar でほぼ一定：½ 乗則により p_CO₂ の 1 桁あたり 0.30 しか動かない）。

- **炭素鋼は不可**（de Waard–Milliams。腐食生成物 FeCO₃ が粒子として流れ込む）。継手・ばね・弁内部品も含む
- **黄銅も不可**（脱亜鉛、Cu²⁺ 汚染）
- **316L は可**。ただし破壊形態は孔食なので**塩化物を入れないこと**——給水は必ず純水
- **PFA / PTFE / PEEK は可**。さらに RH 依存の水分吸着遅れが無いという利点がある
- エラストマは Viton / FFKM（NBR 不可）

推奨 BOM：**PFA 配管 + PTFE シート弁 + 316L 計器本体 + PEEK 継手、純水のみ**

## 8. 計測

| 機器 | 精度 | 用途 |
|---|---|---|
| Michell S8000 冷却鏡式 | ±0.1 °C 露点 ≈ **±0.42 %RH** | **基準器**（第一原理測定、ポリマー交差感度が無い） |
| Vaisala HMP7（容量式） | ±0.8 %RH、T₆₃ = 15 s | プロセス監視（CO₂ 中で S8000 に対し校正） |
| Vaisala DMT340 / DM70 | ±2 °C 露点 ≈ **±8 %RH** | **本系では使用不可**（乾燥ガス用） |

**容量式 RH センサは CO₂ に交差感度がある**（Zych et al., *Sensors* **18**, 2615, 2018）。
機構は CO₂ がポリマーの吸着サイトと直接、および吸着済みの水と間接に相互作用すること。
ただし同論文の定量値は −70 °C・低圧（火星模擬）での結果なので、
**「本系の条件で定量されている」と主張してはいけない。**
正しい書き方は「機構は文献で報告されている。よって我々は運転点の CO₂ 中で冷却鏡に対し校正した」であり、
その校正表を示せば弱点が貢献に変わる。

RH は T と p が分からなければ意味を持たない。**同一断面で T・p・RH を測ること。**
1 kPa の圧力誤差だけで 0.57 %RH になる。

## 9. 感度と制御許容差

| パラメータ | 感度 | ±1 %RH に必要な精度 |
|---|---|---|
| **出力段温度 T_out** | **−4.32 %RH/K** | **±0.23 K** ← 最も厳しい |
| 出力段圧力 p_out | +0.567 %RH/kPa | ±1.76 kPa |

| 一次圧 p₁ | 流量に 1:1（q_m ∝ p₀） | 流量 0.2 % なら ±0.6 kPa |

**温度制御が律速である。** 圧力仕様（±0.88 %）は温度に換算すると 0.12 K 相当でしかなく、
同期排気方式で十分達成できる。

## 10. 安全

| 項目 | 値 |
|---|---|
| 必要換気量（5000 ppm、k = 1） | **422 m³/h** |
| 同（EIGA 推奨の混合係数 k = 3） | **1265 m³/h** = 54 m³ 室で 23 回/h |
| **換気停止時に 5000 ppm に達する時間（54 m³）** | **7.7 分** |
| STEL 30000 ppm 到達 | 50 分 |
| IDLH 40000 ppm 到達 | 67 分 |

**換気が止まれば 8 分で TLV を超える。** これが CO₂ モニタと供給電磁弁のインターロックを
必須とする論拠である。

- 曝露限界：ACGIH TLV-TWA 5000 ppm / STEL 30000 ppm、OSHA PEL 5000 ppm、NIOSH IDLH 40000 ppm
- CGA G-6.14 (2023)：5000 ppm で常時有人場所に可聴＋可視の監視警報、30000 ppm で室内に警報
- **酸素濃度計では代用できない**（EIGA Doc 44：CO₂ は酸素が十分でも危険）。NDIR の CO₂ 直読計を使う
- CO₂ は空気の約 1.5 倍重い。**天井排気は設計ミス。排気は最下部から、給気は上部から**

## 11. 投稿前に確認すべきこと

本作業は外部サイトへの直接アクセス（WebFetch）が遮断された環境で行われた。
参照値は Span–Wagner (1996) / IAPWS-95 / Laesecke–Muzny (2017) / Huber et al. (2016) を実装した
**CoolProp 8.0.0 をローカル実行して生成**し、文献の書誌情報は検索で確認した。
CoolProp は NIST REFPROP と同じ基準相関を実装しているため数値は一致するはずだが、
**投稿前に NIST Webbook または REFPROP で表を再生成し、そちらを引用すること。**

さらに次の 4 点を原著で置き換えることを推奨する：

1. **B₁₂(H₂O–CO₂)** を Meyer & Harvey (2015) *AIChE J.* **61**, 2913 と

   本書の値は GERG-2008 二成分モデルからの導出であり、低密度域は外挿にあたる
2. **C\*(CO₂)** を ISO 9300:2022 Annex B の表（u = 0.1 %, k = 2）または REFPROP から。
   REFPROP のバージョン間で CO₂ の C* は 1 % 近く違いうるので、**EOS のバージョンを明記**すること
3. **f_CO₂** の実測値として Koglbauer & Wendland (2008) *J. Chem. Eng. Data* **53**, 1443 の表と比較
4. **ノズル Cd** は CO₂ で実機校正した値へ（振動緩和で最大 2 %）

## 12. 査読で突かれる 3 点と答え方

1. **「容量式 RH センサを CO₂ 中で使っているが？」**
   → 自分から *Sensors* **18**, 2615 を引用し、機構を認めた上で、
   運転点の CO₂ 中で冷却鏡に対して取った自前の校正表を示す
2. **「結露余裕が 5.6 K しかない。業界慣行は 20 K では？」**
   → 余裕予算表を示し、適用下限は EPA Method 320 の 5 °C であることを述べ、
   減圧弁を上流に置くことで JT の 1.8 K を感度領域から構造的に排除したことを示す
3. **「CO₂ を絞るとドライアイスが出ないか？」**
   → 三重点 517.95 kPa、昇華点 194.7 K、μ_JT = 1.06 K/bar ⇒ 必要差圧 約 89 bar に対し
   利用可能 2.8 bar。**32 倍の余裕**として定量的に答える
