# 加湿 CO₂ 高速流量切替供給系 — 設計計算

出力段で **20 kPa(ゲージ) / 20 °C / RH 70 %** を保ちながら、
**30 NLPM ⇄ 15 NLPM を 30 ms ごとに切り替える** CO₂ 供給系の設計計算一式。

| ファイル | 内容 |
|---|---|
| `out/CO2加湿ガス供給系_設計計算.xlsx` | **主成果物。** 入力パラメータを変えると全結果が再計算される設計計算ブック（12 シート・910 式） |
| `docs/設計報告書.md` | 設計判断の根拠、物理、文献、査読対策をまとめた報告書 |
| `src/physics.py` | 物性・湿度熱力学の参照実装（Python） |
| `src/system.py` | 系統レベルのモデル（ノズル、プレナム、音響、換気） |
| `src/xlutil.py` | Excel 数式ジェネレータと書式 |
| `src/build_wb.py` | ブックを生成するスクリプト |
| `docs/design_numbers.txt` | 参照実装が出した設計点の数値 |

## ブックの使い方

1. `01_入力` の**黄色セル（青字）だけ**を編集する。
2. `03_湿度状態点` 下部の **★必要飽和器温度 T_sat** を読み、`01_入力` に入れ戻す。
3. 同シート最下行の **「S4 で達成される RH と目標との差」が 0** になれば整合完了。
4. `10_検証` が全項目合格であることを確認してから結果を使う。

## 再生成

```bash
pip install openpyxl
cd src && python3 build_wb.py
# 全数式の再計算（LibreOffice Calc が必要）
python3 <xlsx-skill>/scripts/recalc.py ../out/CO2加湿ガス供給系_設計計算.xlsx 480
```

## 検証状況

- LibreOffice Calc で全数式を再計算 — **910 式・エラー 0 件**
- 内蔵検証シート `10_検証` — **32 / 32 合格**（Span–Wagner 1996 / IAPWS-95 / IAPWS G7-04 と比較）
- Python 独立実装との突合 — **40 / 41 一致**（残り 1 件は差分法の違いで結論に影響なし）
