# シフト組み立て支援システム（障害福祉サービス事業所向け）

`shift_scheduler.html` を **ブラウザで開くだけ**で動く、単一ファイルの勤務シフト作成支援アプリです。
インストール・サーバー・ネットワーク接続は不要で、データはブラウザ内（localStorage）にのみ保存されます。

対象サービス種別

- 放課後等デイサービス
- 児童発達支援
- 生活介護

## このアプリが解くこと

福祉施設のシフト作成では、次の3つを同時に満たす必要があります。

1. **減算を食らわない** … 人員欠如減算、児発管・サビ管欠如減算、定員超過利用減算、開所時間減算 など
2. **加算を取り切る** … 児童指導員等加配加算、専門的支援体制加算、看護職員加配加算、人員配置体制加算、福祉専門職員配置等加算 など
3. **労基法を守る** … 週の労働時間、連続勤務日数、公休日数、勤務間インターバル

本アプリは、この3つを**同時に評価関数へ組み込んで**1か月分のシフトを自動生成し、
組み上がったシフトに対して加算・減算の充足状況をリアルタイムに判定します。

## 使い方

1. **事業所設定** … サービス種別・定員・営業日・算定する加算を登録します
2. **職員台帳** … 職種・雇用形態・週所定労働時間・保有資格・入職日を登録します（「サンプル職員を投入」で試せます）
3. **勤務記号** … 早番／日勤／遅番などの時間帯と勤務時間数を定義します
4. **必要人数** … 利用者数を入れると、指定基準から日別の必要配置数を自動算出します
5. **シフト表** … 「シフトを自動生成」で1か月分を作成し、セルをクリックして手直しします
6. **加算・減算判定** … 減算リスク、加算の充足状況、労務チェックを確認します
7. **出力** … シフト表・勤務形態一覧表・判定結果をCSV出力、シフト表はA3横で印刷できます

## 自動生成の仕組み

貪欲法で初期解を作り、**焼きなまし法（Simulated Annealing）** で改善します。
評価関数の重みは、法令リスクの重さの順に設定しています。

| 制約 | 重み | 内容 |
|---|---|---|
| 在所職員の欠如 | 4000 | 直接支援職員が誰も出勤しない日 |
| 基準人員の不足 | 1000 | 児童指導員等の配置基準（人員欠如減算に直結） |
| 児発管・サビ管の不在 | 800 | 個別支援計画の作成体制 |
| 看護職員の不在 | 600 | 生活介護の人員基準 |
| 加配加算分の不足 | 300 | 選択した加算の算定要件 |
| 連続勤務の超過 | 200/日 | 労基法 |
| 週法定労働時間の超過 | 120/時間 | 労基法 |
| 希望休の未充足 | 400/件 | 職員満足度 |
| 所定労働時間の超過 | 45/時間 | 過剰な勤務の抑制 |
| 過剰配置 | 4×人数² | 2乗評価により日ごとの配置人数を平準化 |

「固定・希望休を保持」にチェックを入れると、手入力したセルと希望休は自動生成で動きません。
シフト表のセルは、クリックで記号を記入、右クリックで固定／固定解除、氏名クリックで希望休の設定ができます。

## 判定ロジックの考え方

人員基準の判定方法は、サービス種別によって異なります。本アプリはこの違いを作り分けています。

- **児童発達支援・放課後等デイサービス**
  児童指導員又は保育士を「サービス提供時間帯を通じて配置する**実人数**」の基準です。
  障害児10人までは2人、以降5人を増すごとに＋1人。あわせて、配置する直接支援職員の**半数以上**が
  児童指導員又は保育士である必要があります。日別の実人数で判定します。

- **生活介護**
  人員基準は**常勤換算方法（月次）**の要件です。平均利用者数を平均障害支援区分に応じた比率
  （区分5以上=3:1／区分4以上5未満=5:1／区分4未満=6:1）で除した必要常勤換算数と、
  月の勤務延べ時間から算出した常勤換算数を比較して判定します。
  日別の配置数は、必要常勤換算数を営業日数と1日の平均勤務時間で按分した**目安**として表示します。

児発管・サビ管欠如減算と看護職員の配置は**員数要件**（配置人数）で判定し、
日々の不在は減算ではなく「注意」として表示します。

## 注意事項

- 内蔵している基準値・減算率は**令和6年度（2024年度）障害福祉サービス等報酬改定をベースにした初期値**です。
  経過措置、自治体独自の取扱い、その後の改定により変わります。
  実際の届出・請求の前には、必ず最新の告示、留意事項通知および指定権者の指導内容をご確認ください。
- しきい値は「事業所設定 → 基準値の調整」から事業所ごとに変更できます。
- 本アプリの判定は**シフトから確認できる範囲**に限られます。
  実際の支援内容、利用実績、書類整備の状況までは判定できません。
- 減算率の合計は単純合計で表示しています。実際の算定順序・上限は報酬告示をご確認ください。

## データの保存

- 入力内容はブラウザのlocalStorageに自動保存されます（ブラウザやPCが変わると引き継がれません）
- 画面右上の「バックアップ」でJSONファイルに書き出し、「復元」で読み込めます
- 事業所・月ごとにバックアップを取る運用を推奨します

## 動作環境

Chrome / Edge / Safari / Firefox の最新版。ファイルをダブルクリックして開くだけで動作します。
