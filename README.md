# Shiftly 福祉 ｜ 障害福祉サービス事業所向け シフト組み立て支援システム

`shift_scheduler.html` を **ブラウザで開くだけ**で動く、単一ファイルの勤務シフト作成支援アプリです。
インストール・サーバー・ネットワーク接続は不要で、データはブラウザ内（localStorage）にのみ保存されます。

## 対応サービス種別

| 種別 | 人員基準の判定方法 | 特徴 |
|---|---|---|
| 放課後等デイサービス | 実人数（サービス提供時間帯を通じた配置） | 児童指導員等の加配加算、半数要件、開所時間減算 |
| 児童発達支援 | 同上 | 同上 |
| 生活介護 | 常勤換算（月次） | 平均障害支援区分による配置比率、人員配置体制加算 |
| 就労継続支援B型 | 常勤換算（月次） | 基本報酬区分 10:1／7.5:1／6:1、目標工賃達成指導員配置加算 |
| 共同生活援助（グループホーム） | 常勤換算（月次・職種別） | 世話人と生活支援員を別々に判定、**夜勤・宿直**、夜間支援等体制加算 |

## このアプリが解くこと

福祉施設のシフト作成では、次の3つを同時に満たす必要があります。

1. **減算を食らわない** … 人員欠如減算、サビ管・児発管欠如減算、定員超過利用減算、開所時間減算 など
2. **加算を取り切る** … 児童指導員等加配加算、専門的支援体制加算、人員配置体制加算、目標工賃達成指導員配置加算、夜間支援等体制加算、福祉専門職員配置等加算 など
3. **労基法を守る** … 週の労働時間、連続勤務日数、公休日数、勤務間インターバル、夜勤明けの取扱い

本アプリは、この3つを**同時に評価関数へ組み込んで**1か月分のシフトを自動生成し、
組み上がったシフトに対して加算・減算の充足状況をリアルタイムに判定します。

## 事前準備は「事業所情報」と「職員情報」だけ

必須入力は次の4項目です。それ以外はサービス種別から自動設定されます。

- 事業所名
- 利用定員
- 平均障害支援区分（生活介護・グループホームのみ）
- 営業曜日

自動で決まるもの（詳細設定でいつでも調整できます）：

- **勤務記号** … 種別に応じたセットを自動投入（グループホームは夜勤・夜勤明け・宿直つき）
- **日別の利用者数** … 既定で定員と同数
- **日別の必要配置数** … 人員基準と選択した加算から自動算出
- **判定のしきい値・減算率** … 令和6年度報酬改定ベースの初期値
- **営業曜日・定員の初期値** … 種別ごとの標準値

職員は「氏名・職種・雇用形態」の3つが必須です。資格と入職日は任意ですが、
入力すると**算定できる加算を自動で見つけられる**ようになります。
「名前をまとめて登録」で改行区切りの氏名から一括登録できます。

## 使い方

1. **事業所** … 種別を選び、名称・定員・営業曜日を入力。算定する加算をONにする
2. **職員台帳** … 職員を登録（「サンプル職員を投入」で動きを確認できます）
3. **シフト表** … 「シフトを自動生成」で1か月分を作成し、セルをクリックして手直し
4. **加算・減算** … 減算リスク、加算の充足状況、労務チェックを確認
5. **出力** … シフト表・勤務形態一覧表・判定結果をCSV出力、シフト表はA3横で印刷

画面上部のステップ表示が、どこまで終わっているかを示します。

## 自動生成の仕組み

貪欲法で初期解を作り、**焼きなまし法（Simulated Annealing）** で改善します。
評価関数の重みは、法令リスクの重さの順に設定しています。

| 制約 | 重み | 内容 |
|---|---|---|
| 在所職員の欠如 | 4000 | 直接支援職員が誰も出勤しない日 |
| 夜勤の欠如 | 3000 | グループホームの夜間支援体制 |
| 夜勤明けの取扱い違反 | 2500 | 夜勤の翌日に勤務を入れてしまう |
| 宿直の欠如 | 1500 | 夜間支援等体制加算（Ⅱ） |
| 基準人員の不足 | 1000 | 児童指導員等の配置基準（人員欠如減算に直結） |
| サビ管・児発管の不在 | 800 | 個別支援計画の作成体制 |
| 連続勤務の超過 | 900/日 | 労基法 |
| 希望休の未充足 | 400/件 | 職員満足度 |
| 加配加算分の不足 | 300 | 選択した加算の算定要件 |
| 非常勤の契約時間超過 | 130/時間 | 契約違反の抑制 |
| 週法定労働時間の超過 | 120/時間 | 労基法 |
| 常勤の所定労働時間超過 | 45/時間 | 過剰な勤務の抑制 |
| **常勤換算の必要数に対する不足** | **40/時間** | 人員基準そのもの |
| 過剰配置 | 4×人数² | 2乗評価により日ごとの配置人数を平準化 |

常勤換算の不足（40）を、所定労働時間の超過（45）や契約時間の超過（130）より**小さく**設定しています。
これは、**労基法違反や契約違反をしてまで人員基準を満たしにいかない**ためです。
職員が足りない場合は無理なシフトを作らず、減算リスクとして正直に報告します。

「固定・希望休を保持」にチェックを入れると、手入力したセルと希望休は自動生成で動きません。
シフト表のセルは、クリックで記号を記入、右クリックで固定／固定解除、氏名クリックで希望休の設定ができます。

## 判定ロジックの考え方

人員基準の判定方法はサービス種別で異なるため、そこを作り分けています。

- **児童発達支援・放課後等デイサービス**
  児童指導員又は保育士を「サービス提供時間帯を通じて配置する**実人数**」の基準です。
  障害児10人までは2人、以降5人を増すごとに＋1人。あわせて、配置する直接支援職員の
  **半数以上**が児童指導員又は保育士である必要があります。日別の実人数で判定します。

- **生活介護・就労継続支援B型・グループホーム**
  人員基準は**常勤換算方法（月次）**の要件です。月の勤務延べ時間数を常勤職員が勤務すべき
  時間数で除して判定します。日別の配置数は、必要常勤換算数を営業日数と1日の平均勤務時間で
  按分した**目安**として表示します。
  グループホームは世話人（利用者数÷6）と生活支援員（区分3→9:1／区分4→6:1／区分5→4:1／区分6→2.5:1）を
  別々に判定します。

サビ管・児発管および看護職員の配置は**員数要件**（配置人数）で判定し、
日々の不在は減算ではなく「注意」として表示します。

## 注意事項

- 内蔵している基準値・減算率は**令和6年度（2024年度）障害福祉サービス等報酬改定をベースにした初期値**です。
  経過措置、自治体独自の取扱い、その後の改定により変わります。
  実際の届出・請求の前には、必ず最新の告示、留意事項通知および指定権者の指導内容をご確認ください。
- しきい値は「詳細設定 → 判定のしきい値」から事業所ごとに変更できます。
- 本アプリの判定は**シフトから確認できる範囲**に限られます。
  実際の支援内容、利用実績、書類整備の状況までは判定できません。
- 減算率の合計は単純合計で表示しています。実際の算定順序・上限は報酬告示をご確認ください。
- 宿直は労働基準監督署の許可を前提に、勤務時間数0分として常勤換算から除外しています。

## データの保存

- 入力内容はブラウザのlocalStorageに自動保存されます（ブラウザやPCが変わると引き継がれません）
- サイドバーの「バックアップ」でJSONファイルに書き出し、詳細設定の「復元」で読み込めます
- 事業所・月ごとにバックアップを取る運用を推奨します

## 動作環境

Chrome / Edge / Safari / Firefox の最新版。ファイルをダブルクリックして開くだけで動作します。
ライト／ダークの表示テーマを画面右上で切り替えられます。
