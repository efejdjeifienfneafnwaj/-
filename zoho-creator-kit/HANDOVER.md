## Zoho Creator アプリ作成キットのご案内

Claude Code に「Zoho Creator でアプリにして」と頼んだときに、
**インポートが通る .ds ファイルと、動くウィジェット zip** がそのまま出てくるようにするためのキットです。

### なぜ必要か

Claude は Zoho Creator の `.ds` ファイルの文法を知りません。
一般的な設定ファイルの見た目から推測して書くため、そのままでは
**「アプリの作成中に問題が発生しました」とだけ表示されて、原因が分からないまま止まります。**

SDK の呼び方も同じで、パラメータ名を1文字間違えるだけで（`reportName` / 正しくは `report_name`）
エラーも出ないまま画面が空になります。

このキットには、**実際に動いている Creator アプリから読み取った正しい書き方**が入っています。

### 入れ方

添付の zip を展開し、プロジェクトの以下の場所に置いてください。

```
（プロジェクトのフォルダ）/
└── .claude/
    └── skills/
        └── zoho-creator-app/     ← ここに zip の中身を置く
            ├── SKILL.md
            ├── reference/
            ├── template/
            └── verify/
```

**Claude Code に任せる場合**は、zip を渡して次のように頼んでください。

> この zip を `.claude/skills/zoho-creator-app/` に展開してください。

### 入ったか確かめる

Claude Code に次のように聞いてください。

> zoho-creator-app スキルは使えますか。`.ds` の `application` 行はどう書くのが正しいですか。

**「引用符で囲む（`application "アプリ名"`）」**と答えれば、正しく読み込まれています。

### 使い方

あとは普通に頼むだけです。

> この HTML ツールを Zoho Creator のアプリにしてください。

Claude が `.ds` の生成 → ウィジェットの作成 → 検証、まで自動で進めます。

### 入っているもの

| 種類 | 内容 |
|---|---|
| リファレンス | `.ds` の文法／zip の構造と SDK の呼び方／**実際に踏んだ落とし穴11件**／完成前チェックリスト |
| 生成スクリプト | `.ds` を生成。スキーマを書き換えるだけ（手書きだと12フォームで3,000行になります） |
| ウィジェット雛形 | Creator 接続とデモモードの両対応。そのまま動きます |
| 検証スクリプト3本 | 項目名の突き合わせ／SDK 呼び出しの検証／ブラウザでの動作確認 |

### ひとつだけご注意

**`.ds` の正解は、その環境の Creator がエクスポートしたものにしかありません。**

このキットの文法は1つのアプリの出力から書き起こしたもので、
ルックアップ・選択肢・日付型などは確認できていません。

そのため「**Creator 側のフィールドは text / textarea / number の3種類だけ使い、
意味づけはウィジェット側の JavaScript が持つ**」という方針で全体を組んでいます。
未確認の型に依存しなければ、取り込みが失敗する余地がありません。

より確実にしたい場合は、御社の Creator で既存アプリを開き
**設定 → アプリケーションIDE → DSファイルのエクスポート** を実行し、
出てきたファイルを `reference/` に追加してください。それが御社環境での正解になります。
