# 自動リマインド（未修了の人へ週1回メール）

## しくみ

| 役割 | 誰が |
|---|---|
| 「誰に・どんな文面を送るか」を1人1行で用意する | ウィジェット（表 `Lms_Remind_Form`） |
| 週1回、その表を見てメールを送る | Zoho Creator のスケジュール |

ウィジェットは、受講者が記録を保存するたびに自分の行を最新にし、
管理者が「受講者の状況」を開いたとき（1日1回）と、設定の「対象を今すぐ更新する」で
全員ぶんを見直します。未修了が無くなった人は `active` が `false` になり、送られません。

文面は「e-ラーニング → 設定 → 自動リマインド」で変えられます。
`{name}`（お名前）`{list}`（未修了の一覧）`{count}`（件数）`{portal}`（ポータル名）が使えます。

## Creator に足す表：Lms_Remind_Form（レポート名 Lms_Remind_Report）

| 項目名 | 種類 | 何が入るか |
|---|---|---|
| remind_key | 1行テキスト | 氏名（1人1行のカギ） |
| person_name | 1行テキスト | 氏名 |
| email | 1行テキスト | 宛先 |
| pending_count | 数値 | 未修了の数 |
| pending_list | 複数行テキスト | 未修了の一覧（文面に入っているもの） |
| mail_subject | 1行テキスト | 送る件名（本人の名前などを入れ終わったもの） |
| mail_body | 複数行テキスト | 送る本文（同上） |
| active | 1行テキスト | `true` なら送る、`false` なら送らない |
| refreshed_at | 1行テキスト | ウィジェットが更新した日時 |
| last_sent_on | 1行テキスト | Creator が送った日（任意） |

まとめた `lms-widget/PortalNavi.ds` にはこの表も入っています。

## Creator 側の設定（週1回のスケジュール）

1. Creator のアプリを開き、**ワークフロー → 「スケジュール」**で新規作成
2. 実行のタイミング：**毎週**（例：月曜 9:00）
3. 対象：フォーム `Lms_Remind_Form`、条件 **`active == "true"`**
4. 動作：**メールを送信**
   - 宛先：`${email}`（項目 email）
   - 件名：`${mail_subject}`
   - 本文：`${mail_body}`
5. 保存して有効にする

件名と本文はウィジェットが本人向けに作り終えた文章なので、Creator 側では
項目をそのまま差し込むだけです。文面を変えたいときはウィジェットの設定から変えてください。

### スケジュールの画面に「メールを送信」の動作が無い場合

お使いの Creator の版によっては、スケジュールの動作が Deluge（関数）しか選べないことがあります。
その場合だけ、次の6行を貼り付けてください（この用途に限った最小のものです）。

```
for each r in Lms_Remind_Form [active == "true"]
{
    sendmail
    [
        from : zoho.adminuserid
        to : r.email
        subject : r.mail_subject
        message : r.mail_body
    ]
    r.last_sent_on = zoho.currentdate.toString("yyyy-MM-dd");
}
```

## 注意

- メールアドレスが未登録の人には送れません（行を作りません）。名簿で入れてください。
- 「送る／送らない」の印は、誰かがアプリを開いたときに更新されます。
  全員が何週間もアプリを開かない場合は、管理者が設定の「対象を今すぐ更新する」を押してください。
- リマインドを止めるときは、設定で「自動リマインドを使う」を外して保存します（全員 `false` になります）。
