# 名簿（Lms_Person_Form）に足す項目

3つのアプリを1つにしたので、名簿は1つです。社内申請とプロフィール（顔写真）が使う
項目を、`Lms_Person_Form` に足してください。**項目名（英字）はこの綴りのまま**入れてください。

ウィジェットは、これらの項目に**値が入っているときだけ**送ります。
足す前でも e-ラーニングとコネクトは動きますが、社内申請の「設定・マスタ → 社員」で
上長や役職を保存すると、項目が無い環境では保存に失敗します。先に足してください。

| 項目名 | 種類 | 表示名（例） | 使うところ |
|---|---|---|---|
| kana | 1行テキスト | フリガナ | 社内申請 |
| manager_name | 1行テキスト | 上長 | 社内申請（承認経路の「直属上長」） |
| join_date | 1行テキスト | 入社日 | 社内申請 |
| leave_balance | 数値 | 有給残日数 | 社内申請 |
| deputy_name | 1行テキスト | 代理人 | 社内申請 |
| deputy_from | 1行テキスト | 代理開始日 | 社内申請 |
| deputy_to | 1行テキスト | 代理終了日 | 社内申請 |
| is_active | 1行テキスト | 在籍（true/false） | 社内申請 |
| photo | 複数行テキスト | 顔写真（データURI） | プロフィール・メンバー・掲示板 |
| profile | 複数行テキスト | 自己紹介 | プロフィール・メンバー |

`title`（役職）はもともとあります。社内申請の承認経路は役職名（部長・課長など）で
承認者を決めるので、社内申請を使う方には役職を入れてください。

## 顔写真の大きさ

写真は、選んだ時点で正方形に切り取り、128px の JPEG にして保存します。1人あたり数KB です。
250人ぶんでも 1MB 程度なので、Creator の表にそのまま入れて問題ありません。
端末側の控えには写真を入れず、開くたびに Creator から読みます（端末の空きを食いつぶさないため）。

## 社内申請の表

社内申請が使う12の表（Wf_*）も、**同じ Creator アプリの中**に要ります。
別のアプリに置いたままだと、ウィジェットから届きません。
すべてをまとめた `lms-widget/PortalNavi.ds`（新しいアプリとして取り込む用）を用意してあります。
既存のアプリに足す場合は、`shinsei/ShanaiShinsei.ds` の各フォームの項目を手で作ってください。

## 自動リマインドの表

未修了の人に週1回メールを送るための表 `Lms_Remind_Form` も要ります。
項目と Creator 側のスケジュールの設定は `docs/自動リマインド.md` を見てください。
