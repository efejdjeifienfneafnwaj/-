# 社内コミュニティ（コネクト）の表を Creator に足す

掲示板とサンクスカードは、Creator の表（フォーム）を2つ使います。
e-ラーニングのアプリに、次の2つのフォームを足してください。
**項目名（フィールド名）は英字のものを、そのままの綴りで**入れてください。
ウィジェットはこの名前で読み書きします。表示名は自由です。

## 1. Lms_Post_Form（投稿）　レポート名: Lms_Post_Report

| 項目名 | 種類 | 表示名（例） | 何が入るか |
|---|---|---|---|
| post_key | 1行テキスト | 投稿キー | ウィジェットが付ける番号 |
| kind | 1行テキスト | 種別 | post＝掲示板 / thanks＝サンクス |
| author_name | 1行テキスト | 投稿者 | 名簿の氏名 |
| author_email | 1行テキスト | 投稿者メール | ログインのメールアドレス |
| to_name | 1行テキスト | 宛先（サンクス） | サンクスを贈った相手 |
| title | 1行テキスト | 件名 | いまは未使用 |
| body | 複数行テキスト | 本文 | |
| target | 1行テキスト | 宛先の職種 | 空＝全員 |
| posted_at | 1行テキスト | 投稿日時 | |
| deleted | 1行テキスト | 削除 | 「あり」なら削除済み |

## 2. Lms_React_Form（いいね・コメント）　レポート名: Lms_React_Report

| 項目名 | 種類 | 表示名（例） | 何が入るか |
|---|---|---|---|
| react_key | 1行テキスト | 反応キー | ウィジェットが付ける番号 |
| post_key | 1行テキスト | 投稿キー | どの投稿に対してか |
| kind | 1行テキスト | 種別 | like＝いいね / comment＝コメント |
| person_name | 1行テキスト | 名前 | |
| body | 複数行テキスト | コメント本文 | いいねのときは空 |
| at | 1行テキスト | 日時 | |
| deleted | 1行テキスト | 削除 | 「あり」なら削除済み |

## ポータルユーザーの権限

| レポート | ポータル（一般） | 管理者 |
|---|---|---|
| Lms_Post_Report | 全レコードの閲覧・追加・編集 | すべて |
| Lms_React_Report | 全レコードの閲覧・追加・編集 | すべて |

掲示板は全員が全員の投稿を読むものなので、**「自分が作成したレコードのみ」にはしないでください**。
自分以外の投稿が見えなくなります。「編集」も要ります（いいねの取り消しと削除の印付けに使います）。

## 削除について

投稿を消しても行は消しません。`deleted` に「あり」が入るだけです。
経緯をたどれるように残しています。本当に消したいときは Creator の一覧から消してください。

## 同じ内容の .ds

新しいアプリとして作り直すときは、同じフォルダの `LmsConnect.ds` に
この2つのフォームを .ds の形で置いてあります。

## 3. Lms_Chat_Form（チャット）　レポート名: Lms_Chat_Report

まとめた `lms-widget/PortalNavi.ds` には入っています。

| 項目名 | 種類 | 表示名（例） | 何が入るか |
|---|---|---|---|
| chat_key | 1行テキスト | 発言キー | ウィジェットが付ける番号 |
| room | 1行テキスト | 部屋 | `all`＝全員 / `dept:介護職`＝職種の部屋 / `r-…`＝管理者が作った部屋 |
| chat_month | 1行テキスト | 月 | `2026-09` の形。読み込みを今月・先月に絞るために使う |
| person_name | 1行テキスト | 発言した人 | 名簿の氏名 |
| body | 複数行テキスト | 本文 | 1000文字まで |
| posted_at | 1行テキスト | 日時 | |
| deleted | 1行テキスト | 削除 | 「あり」なら削除済み |

### チャットのしくみ

- 部屋は「全員」、職種ごと（職種の一覧から自動）、管理者が作る部屋の3種類です。
  管理者が作った部屋の一覧は、設定（コース定義と同じ行）に入ります。
- 職種の部屋・「見られる人」を決めた部屋は、その人たちと管理者の一覧にだけ出ます。
  ただし中身は同じ表に入るので、**技術的には職員みんなが読めます**。
  個人どうしのやりとりや、利用者さまの個人情報を書く場にはしないでください（画面にも注意書きを出しています）。
- 読み込むのは今月と先月の発言だけです。それより前は「○月の発言を読む」で1か月ずつ読みます。
- チャットを開いている間は、いまの部屋を8秒ごとに読み直します。
  ほかの画面にいるときは、90秒ごとの新着確認でメニューに未読の数を出します。
- 発言を消すと、行は残したまま「削除あり」の印を付けます（あとから経緯をたどれるように）。
  消せるのは本人と管理者です。
