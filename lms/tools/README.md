# 確認用のツール

## スモークテスト.js
Chromium で実際にウィジェットを開いて、入口から管理画面までを通しで操作し、
「受講者に管理画面への道が出ていないか」を毎回確かめます。

```
npm install playwright-core            # 初回だけ
NODE_PATH=./node_modules node tools/スモークテスト.js
```

Chromium の場所が違うときは `CHROME=/path/to/chrome` を付けてください。

## テスト_コース編集.js
コースを作り、テストの設問と選択肢を打ち込み、保存して開き直すまでを操作します。

## テスト_ログインと権限.js
Zoho Creator にログインしている状態をブラウザの中で作り、
「誰がどのメニューを開けるか」を、システム管理者・部門管理者・受講者・
名簿に無い人のそれぞれで確かめます。

## テスト_名簿と職種.js
職員の1人ずつ登録、登録済みの方の編集（氏名・職種・権限）、氏名を直したときの
受講記録の付け替え、名簿からの削除、職種の追加・改名・削除を操作して確かめます。

## テスト_コネクト.js
3人が同じ Creator（テスト用サーバー）を見ている状態で、掲示板への投稿・いいね・
コメント・サンクスカード・削除・職種あての出し分けを確かめます。
